PATCH DE BRANDING — RESIBULANDO

Este pacote aplica a nova identidade visual no projeto:
- troca o nome visível de DocMap para Resibulando
- aplica a nova logo no menu lateral, login e loading inicial
- adiciona favicon
- atualiza o texto curto da marca para "Mapa até a residência"

ARQUIVOS INCLUÍDOS
- app.js
- style.css
- index.html
- login.html
- dashboard.html
- cronograma.html
- ambientacao.html
- flashcards.html
- caderno-erros.html
- questoes-simulados.html
- editais.html
- configuracoes.html
- estatisticas.html
- logo-resibulando.png
- favicon.png

COMO USAR
1. Faça backup dos seus arquivos atuais.
2. Substitua os arquivos da raiz do projeto pelos arquivos deste pacote.
3. Confirme que a imagem logo-resibulando.png ficou na raiz do projeto.
4. Faça commit e push no GitHub Pages.

OBSERVAÇÃO
- IDs internos, chaves locais e nomes técnicos "docmap" no JavaScript foram mantidos para não quebrar a aplicação.
- O patch muda a MARCA exibida ao usuário, não a estrutura do banco.
