# Estrutura do projeto

- `*.html` — páginas públicas; permanecem na raiz para preservar as URLs.
- `assets/css/` — folhas de estilo.
- `assets/js/` — JavaScript da aplicação.
- imagens principais — ainda na raiz para preservar referências dinâmicas existentes.
- `docs/archive/` — documentação, notas de instalação e registros antigos.
- `tools/` — scripts auxiliares de manutenção.
- `CNAME` — domínio customizado do GitHub Pages.

Ao adicionar novos arquivos, mantenha CSS e JS nas pastas de assets correspondentes.
