INSTALAÇÃO RECOMENDADA
======================

Use um Codespace do GitHub ou uma cópia local do repositório.

1. Extraia estes arquivos na RAIZ do projeto:
   - ambientacao-v18.1.js
   - dashboard-v18.1.js
   - aplicar_v18_1.py

2. Rode:

   python aplicar_v18_1.py

3. Depois:

   git add .
   git commit -m "CCQ somente no dashboard"
   git push

4. No navegador:
   Ctrl + Shift + R

Não precisa rodar SQL.
