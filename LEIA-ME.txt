COMO APLICAR
============

Recomendado: GitHub Codespaces.

1. Extraia APLICAR_V19.py na RAIZ do repositório.

2. Rode:

   python APLICAR_V19.py

3. Se aparecerem todos os ✓, rode:

   git add ambientacao.html ambientacao.css ambientacao.js dashboard.html dashboard.js
   git commit -m "Repara agenda, CCQ e ambientacao"
   git push

4. Depois, no navegador:

   Ctrl + Shift + R

BACKUP
======

VALIDAÇÃO
=========

O instalador verifica:
- agendaState;
- loadAgenda;
- controles Semana/Mês;
- ausência do CCQ na Ambientação;
- CCQ fixo no Dashboard;
- integração do Caderno;
- chama da ofensiva;
- tamanho e centralização do CCQ.

Se Node estiver disponível, também roda:

node --check ambientacao.js
node --check dashboard.js
